# Contributing

This is a historical archive of the original Kyo. The app code and project are intentionally preserved, so feature changes, refactors, and modernization belong in your own fork.

Documentation corrections are welcome. Keep them focused and explain what was inaccurate.

Original documentation contributions are accepted under GPL-3.0-only with the attribution term in [source notes](SOURCE-NOTES.md). Keep any third-party notices intact and only submit work you have the right to share.
