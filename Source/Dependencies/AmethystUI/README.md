# AmethystUI
![Logo Text](amethystUI-Banner.png)

AmethystUI is a UI library for SwiftUI, featuring fluid and well-documented elements. It is designed to be a crucial part of Faux Fox apps.

## Overview

AmethystUI is designed to simplify the process of creating beautiful user interfaces in SwiftUI. It provides a collection of fluid and responsive UI elements, making it easier to build user-friendly and visually appealing apps.

## Features

- Fluid and responsive UI elements
- Comprehensive documentation for easy integration
- Ideal for Faux Fox apps and more

## Getting Started

To get started with AmethystUI, check out our [documentation](./documentation) for detailed information on installation and usage.

## Usage

To use AmethystUI in your SwiftUI project, you can import it using Swift Package Manager (SPM). Here are the steps:

1. **Open your Xcode project:**

   Open your existing SwiftUI project in Xcode or create a new one.

2. **Add AmethystUI as a Swift Package:**

   - In Xcode, go to "File" > "Swift Packages" > "Add Package Dependency."

3. **Select Target:**

   - In the package options, make sure to select the target(s) where you want to use AmethystUI.
   - Click the "Finish" button.

4. **Import AmethystUI:**

   In your Swift source files where you want to use AmethystUI, simply add the following import statement:

   ```swift
   import AmethystUI
   ```
